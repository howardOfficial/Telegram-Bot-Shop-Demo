# Telegram-бот: Магазин (Демо)

Пример интерактивного бота-витрины.

Функции: Инлайн-меню, каталог товаров, карточки товаров (описание, цена), имитация покупки.
Стек: Python, pyTelegramBotAPI (telebot).

Как запустить:

Установите библиотеку: pip install pyTelegramBotAPI
Замените ТВОЙ_ТОКЕН на токен вашего бота.
Запустите: python bot.py
